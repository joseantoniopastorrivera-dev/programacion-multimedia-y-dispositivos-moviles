# 🎮 Programación Multimedia y Dispositivos Móviles (PMDM)

C# programming, Unity game engine, multimedia systems, and interactive logic coursework for 2nd year of DAM (Desarrollo de Aplicaciones Multiplataforma) / Transición de Java a C#, ejercicios de programación en consola, lógica de control, desarrollo con Unity y sistemas multimedia del módulo de PMDM impartido en el IES Isidra de Guzmán.

---

## 🗂️ Estructura del Repositorio

El repositorio se organiza de forma modular por bloques de práctica y contenidos del curso:

* **`transicion-java-csharp/`**: Adaptación de Java a C# con ejercicios de consola (.NET):
  * `01-conceptos-basicos-y-condicionales/`: tipos de datos, propiedades, métodos en PascalCase y condicionales.
  * `02-bucles/`: estructuras de repetición y arrays.
  * `03-juegos/`: juegos interactivos de consola (como *Piensa y Adivina*). Los enunciados de *Adivina y Piensa* y *Piensa y Adivina* están en `enunciados/`.
* **`fichas-unity/`**: Fichas teóricas de Unity de la 1ª evaluación (PDF), numeradas del 1 al 14:
  * `ficha-01` a `ficha-03`: entorno de Unity, espacio de trabajo y ventanas, y GameObject.
  * `ficha-04` a `ficha-07`: `Vector2` y `Vector3`, `Transform`, nuevo Input System y el atributo `[SerializeField]`.
  * `ficha-08` a `ficha-11`: `Instantiate`, prefabs, colisiones y triggers 2D, y `Destroy`.
  * `ficha-12` a `ficha-14`: tiempo (`Time.deltaTime` y framerate), corrutinas y `Random`.
  * `caso-practico/`: paquete de Unity (`.unitypackage`) con el caso práctico que ilustra las fichas.

---

## 📚 Bloques Temáticos Principales

1. **Transición a C#**: Diferencias clave con Java, flujos de ejecución, uso de `Console`, propiedades automáticas y manejo de cadenas y colecciones (`List<T>`).
2. **Algoritmia y Lógica**: Resolución de problemas mediante bucles, condicionales avanzados y funciones estructuradas.
3. **Desarrollo en Unity**: Introducción al motor, GameObjects y `Transform`, Input System, prefabs e instanciación, colisiones, tiempo, corrutinas y scripting orientado a objetos en C#.
