# 🎮 Programación Multimedia y Dispositivos Móvlies (PMDM)

C# programming, Unity game engine, multimedia systems, and interactive logic coursework for 2nd year of DAM (Desarrollo de Aplicaciones Multiplataforma) / Transición de Java a C#, ejercicios de programación en consola, lógica de control, desarrollo con Unity y sistemas multimedia del módulo de PMDM impartido en el IES Isidra de Guzmán.

---

## 🗂️ Estructura del Repositorio

El repositorio se organiza de forma modular por bloques de práctica y contenidos del curso:

* **`Transicion-Java-C#/`**: Adaptación de Java a C# con ejercicios de consola (.NET):
  * `01-Conceptos-Basicos-Y-Condicionales/`: tipos de datos, propiedades, métodos en PascalCase y condicionales.
  * `02-Bucles/`: estructuras de repetición y arrays.
  * `03-Juegos/`: juegos interactivos de consola (como *Piensa y Adivina*).
* **`Proyecto01/`**: Primer proyecto de Unity 6 (URP e Input System): escenas, scripts de comportamiento y lógica de componentes en C#.

---

## 📚 Bloques Temáticos Principales

1. **Transición a C#**: Diferencias clave con Java, flujos de ejecución, uso de `Console`, propiedades automáticas y manejo de cadenas y colecciones (`List<T>`).
2. **Algoritmia y Lógica**: Resolución de problemas mediante bucles, condicionales avanzados y funciones estructuradas.
3. **Desarrollo en Unity**: Introducción al motor, físicas, lógica de componentes y scripting orientado a objetos en C#.
